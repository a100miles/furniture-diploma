## 📝 Project Description
The project aims to create a web-based application that leverages artificial intelligence to assist users in selecting furniture and planning their room layouts in 3D. 

### Key Features
* **Personalized AI Recommendations:** Generates furniture and layout suggestions tailored to user preferences, specific room dimensions, and chosen aesthetic styles.
* **Interactive 3D Visualization:** Enables users to map out and view their room designs in a fully 3D environment.
* **Simplified Decision-Making:** Provides a clear, visual representation of furniture scale and placement to help users make informed purchasing and design choices.
