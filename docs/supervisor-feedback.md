# Supervisor Feedback

**Task:** DIP-12 · **Supervisor:** Kashkimbayeva Nurzhamal

The committee checks whether the supervisor reviewed the *substance* of the work and whether the review led to *meaningful improvements*. Each comment is therefore recorded with the decision taken and a link to the commit or pull request that implements it.

> Record only feedback the supervisor actually gave. Comments may also be left directly on pull requests (add the supervisor as a reviewer); copy the key ones here.

## How to use

1. Before a meeting, list the deliverables to review (with links).
2. During/after the meeting, add one row per comment.
3. Decide: **Accepted** (with change), **Partially accepted**, or **Not accepted** (with reason).
4. Link the PR/commit and the YouTrack task once the change is made.
